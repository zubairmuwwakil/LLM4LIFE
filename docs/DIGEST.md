# Daily Digest

_Last updated: 2026-08-27_

A daily cross-system digest is enabled for approximately **8:00 AM America/Toronto**.

## Purpose

The digest should reduce cognitive load, not create a new inbox.

It should answer:

1. What matters most today?
2. What changed?
3. What is becoming neglected?
4. What can safely be ignored?
5. What did automation already handle?
6. Are any tools/services wasting money or creating friction?

## Current sections

### Top 3 priorities for today

Rank across available systems using:

- urgency
- impact
- dependencies/blockers
- time sensitivity
- observed behavior

Briefly explain why each item made the top three.

### Needs attention today

Important exceptions or actions that should not be buried inside category summaries.

### Work / engineering

Relevant GitHub, Jira, Slack, CI/build, release, or engineering changes.

### Personal / admin

Relevant personal actions, email/admin state, household/life operations, and similar items.

### Upcoming deadlines

Time-sensitive upcoming commitments and expiration/renewal dates.

### Neglected but important

Resurface meaningful items that have become stale, especially items sitting roughly **7–14+ days** without progress.

Do not resurrect old clutter merely because it is old.

### What can be ignored today

Explicitly identify low-value, non-urgent, duplicative, or safely deferrable items.

This section is important: the system should protect attention, not simply rank an ever-growing pile.

### Cleanup performed

Report low-risk, reversible cleanup that the AI performed autonomously.

### Learned preferences

Only show this section when a meaningful behavioral pattern or prioritization adjustment was learned.

Examples:

- repeatedly deferred class of task
- repeatedly promoted class of task
- manual routing overrides that suggest a better ownership rule

### Tool ROI opportunities

The AI may recommend:

- cancel
- downgrade
- consolidate
- replace
- add a new tool/integration

But recommendations should be evidence-driven.

Prefer extracting more value from existing capabilities before adding another paid subscription.

Every recommendation should state:

- concrete benefit
- what it replaces or improves
- why the evidence justifies the change

Avoid novelty-driven tool sprawl.

### Automated actions taken

Summarize meaningful actions already completed by automation/AI.

## Noise controls

- deduplicate repeated signals;
- prioritize exceptions over routine success;
- include direct links/IDs when useful;
- omit empty sections when that improves readability;
- if nothing important happened, say so briefly.

## Relationship to the activity log

The digest is a **human attention surface**.

The AI Activity Log is an **audit surface**.

Do not dump the complete activity log into the daily digest. Summarize only what is useful for decision-making.
